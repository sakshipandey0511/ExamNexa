What each channel actually measures in this build

Eye gaze

The face mesh returns iris landmarks 468–477 plus ARKit-style blendshapes. Horizontal gaze is (lookOutLeft + lookInRight)/2 − (lookOutRight + lookInLeft)/2, vertical is the up minus down pair, both measured against the neutral position captured during calibration. Blinks above 0.5 suppress the reading so a blink is never read as a glance. Eyes off centre for more than 1.2 s raises an event — this fires even when your head never moves, which is the case the old geometric version could not see at all.

Head pose

Real yaw, pitch and roll in degrees from facialTransformationMatrixes, decomposed in YXZ order and offset by your calibrated neutral. No longer inferred from skin-mask asymmetry.

Prohibited objects

COCO-SSD with the lite MobileNet v2 base, run on a 250 ms interval off the main detection loop. Watched classes and their severity: cell phone 0.95, laptop 0.85, tv or monitor 0.85, book 0.70, remote 0.55, and any second person 0.95. Anything under 0.55 confidence is discarded. Swap in YOLOv8-Nano by replacing the loader with ONNX Runtime Web and mapping its class indices onto the same table.
